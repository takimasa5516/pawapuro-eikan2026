# パワプロ2026 栄冠ナイン 攻略情報集約Webアプリ

パワプロ2026（栄冠ナイン）の選手育成・チーム強化に必要なあらゆるデータを集約したWebアプリケーションです。ウマ娘攻略ツールのような直感的なUIと高速な検索・フィルター機能を備えています。

## 収録データ・機能一覧

1. **🏟️ 転生スカウト＆リセマラ検索**
   - 全47都道府県の★250以上・金特持ち・キャッチャーB以上の強力転生選手（347名）
   - 地方・都道府県フィルター、ポジションフィルター
   - 金特、キャッチャーA/B、★300以上のワンクリック絞り込み
   - ★能力値・年代・五十音順ソート、お気に入り（キープ）機能
   - リセマラ狙い目年代早見表

2. **✨ 性格・固有戦術・伝令・キャプテン**
   - 全8性格（天才肌、内気、お調子者、熱血漢、クール、したたか、やんちゃ、ごくふつう）
   - 各性格ごとのステータス伸びやすさ（ボーナス能力）
   - 学年別の固有戦術（1年・2年・3年の効果詳細）
   - ベンチからの伝令効果（攻撃時・守備時それぞれのステータスUP・青特付与）
   - キャプテン指名時の発生イベント（練習方針別経験値UP、グラウンドLv+1、テンション等）

3. **🔍 スカウト寸評逆引きツール**
   - 新入生スカウト画面に表示される寸評（「好リードが光る」「威圧感」「キレ」等）から、選手が隠し持つ特殊能力を即座に逆引き特定
   - 優先度ランク（S, A, B）、地雷寸評の注意点

4. **📅 年間イベントカレンダー**
   - 4月〜翌3月までの年間進行フロー
   - 特別指導イベント（青マス：打撃・守備・走塁・投手の赤特消去確率）
   - 甲子園インタビュー（青マス：攻撃・機動・守備・投手・努力別の青特習得条件）
   - クリスマス（12/24）、確定特訓マス（2/28）、おみくじ（1/1）等の立ち回り解説

5. **🏋️ 通常練習効果・合宿習得青特・戦術経験値**
   - 練習カード別の獲得経験値（ミート系〜特殊練習まで）
   - 進行アイコン倍率、天候・グラウンドLv補正、投手経験値半減ルール
   - 合宿（7月・12月）で各カードから習得できる青特殊能力一覧
   - 試合中の打撃戦術・ミート設定ごとの獲得経験値表

6. **🛡️ 赤特殊能力打消し相関マトリクス**
   - 9大赤特（軽い球、一発、負け運、スロースターター、対ランナー×、ボール先行、三振、チームプレイ×、ムード×）と打ち消し青特の対応表
   - 特別指導、公式戦試合、特能の本、合宿での消去可否○×一覧

7. **🏆 世界大会選出条件・マネージャー特性・試合効果**
   - 日本代表（世界大会）選出条件①〜④の判定基準
   - 世界大会結果（優勝〜予選敗退）による練習効率・テンションへの影響
   - マネージャーの持ち物別特性（赤ペン、笛、バインダー、ノート、なし、男マネ）
   - 試合中の選手の調子（絶好調〜絶不調）によるステータス増減一覧

## 起動方法

### 開発サーバー起動
```bash
npm run dev
```

### 本番ビルド
```bash
npm run build
```
ビルド生成物（`dist/`）は単一のHTML/CSS/JSとしてそのままブラウザで閲覧可能です。
